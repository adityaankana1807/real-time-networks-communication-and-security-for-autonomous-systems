# Real-Time Networks Communication and Security for Autonomous Systems

This repository contains the completed lab manual artifacts for **Real-Time Networks Communication and Security for Autonomous Systems**.

## Contents

- `exp1_executed.ipynb` to `exp13_executed.ipynb`: separate executed notebooks for each experiment.
- `completed_experiments/exp1.docx` and `completed_experiments/exp2.docx`: completed DOCX experiment files prepared from the lab manual.
- `completed_experiments/exp1.html` and `completed_experiments/exp2.html`: HTML versions of the first two completed experiments.
- `REAL_TIME_NETWORKS_COMMUNICATION_AND_SECURITY_FOR_AUTONOMOUS_SYSTEMS_24AAS3414F edited.docx`: source lab manual document.

- objective
