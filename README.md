# Real-Time Networks Communication and Security for Autonomous Systems

This repository contains the completed lab manual artifacts for **Real-Time Networks Communication and Security for Autonomous Systems**.

## Contents

- `exp1_executed.ipynb` to `exp13_executed.ipynb`: separate executed notebooks for each experiment.
- `co 1.ipynb`: separate CO 1 textbook-style notes notebook with runnable timing examples.
- `co-2.ipynb`: separate CO 2 textbook-style notes notebook covering communication protocols and scheduling with runnable examples.
- `completed_experiments/exp1.docx` and `completed_experiments/exp2.docx`: completed DOCX experiment files prepared from the lab manual.
- `completed_experiments/exp1.html` and `completed_experiments/exp2.html`: HTML versions of the first two completed experiments.
- `REAL_TIME_NETWORKS_COMMUNICATION_AND_SECURITY_FOR_AUTONOMOUS_SYSTEMS_24AAS3414F edited.docx`: source lab manual document.

## Notebook Notes

Each experiment notebook includes:

- objective
- complete textbook-style notes for real-time systems fundamentals
- architecture explanation
- formulas and required theory
- in-lab execution
- post-lab execution
- case studies and analysis points
- references/source notes

The notebooks are already executed and include embedded outputs.

The expanded notes cover real-time system definitions, hard/firm/soft classification, task and event types, timing parameters, timing constraints, latency, jitter, throughput, bounded communication, autonomous-system timing chains, formulas, architectures, and case-study interpretation.
