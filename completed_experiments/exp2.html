EXPERIMENT - 2

Latency and Jitter Measurement using Python

Aim / Objective

To measure end-to-end latency and jitter in a real-time communication link using Python and analyse timing performance for autonomous environments.

Description

Latency is the delay between packet transmission and packet reception. Jitter is the variation in latency across packets. Autonomous systems require bounded latency and jitter because irregular control messages can destabilise planning, perception, and actuation loops.

Pre-Requisites

  1. Python 3.x with the time, statistics, and random modules.
  2. Knowledge of packet timestamps and high-resolution clocks.
  3. Understanding of propagation, transmission, queuing, and processing delay.

Pre-Lab Questions and Answers

1. Define latency and jitter, and explain how jitter differs from average latency.
Latency is one packet's end-to-end delay. Jitter is the variation between packet delays, so it captures timing consistency rather than only average speed.

2. Which Python function gives accurate wall-clock measurement for latency, and why?
time.perf_counter() is suitable for elapsed wall-clock measurements because it uses a high-resolution performance counter.

3. How is jitter calculated from per-packet latency values?
A common lab calculation is absolute difference between consecutive latency values: |latency[i] - latency[i-1]|.

4. Why is bounded jitter often more important than low average latency in control loops?
Control loops need predictable sample arrival. A low average can hide occasional large delays that destabilise control.

5. List the four components that make up end-to-end network latency.
Propagation delay, transmission delay, queuing delay, and processing delay.

In-Lab

Hands-on generation of timestamped packets, measurement of per-packet latency, and computation of jitter statistics in Python.

Procedure / Program and Execution

  1. Generate a stream of timestamped packets at fixed send intervals.
  2. Assign each packet a simulated network delay.
  3. Compute receive time and per-packet latency.
  4. Compute jitter as the absolute change between consecutive packet latencies.
  5. Report mean, standard deviation, minimum, maximum, 95th percentile, and 99th percentile latency.
import random
import statistics

def percentile(values, pct):
    values = sorted(values)
    pos = (len(values) - 1) * pct
    lo, hi = int(pos), min(int(pos) + 1, len(values) - 1)
    frac = pos - lo
    return values[lo] * (1 - frac) + values[hi] * frac

rng = random.Random(341402)
latencies = []
for packet_id in range(60):
    send_time_ms = packet_id * 20.0
    network_delay_ms = 8.0 + rng.uniform(-1.4, 1.4) + rng.expovariate(1 / 1.8)
    if packet_id % 17 == 0:
        network_delay_ms += rng.uniform(0, 4.0)
    receive_time_ms = send_time_ms + network_delay_ms
    latencies.append(receive_time_ms - send_time_ms)

jitters = [abs(latencies[i] - latencies[i - 1]) for i in range(1, len(latencies))]
print("packets:", len(latencies))
print("mean latency:", round(statistics.mean(latencies), 2), "ms")
print("average jitter:", round(statistics.mean(jitters), 2), "ms")
print("95th percentile:", round(percentile(latencies, 0.95), 2), "ms")
print("99th percentile:", round(percentile(latencies, 0.99), 2), "ms")

Analysis and Inferences

  • The average latency describes normal packet behaviour, but the 95th and 99th percentile values expose worst-case timing that affects safety-critical traffic.
  • Jitter measures consistency. A link with moderate latency but low jitter may be easier to control than a link with low mean latency and large bursts.
  • Occasional queued packets increase tail latency and can cause stale sensor or actuation messages.

1. What is the difference between latency and jitter in your measured data?
Latency is each packet's delay; jitter is the packet-to-packet change in delay.

2. How did you timestamp packets to measure one-way or round-trip latency?

Mean, standard deviation, minimum, maximum, P95, P99, and average jitter. Together they describe central tendency, spread, tail risk, and consistency.

1. Inject artificial random delay (0-20 ms) into your packet stream to emulate congestion, then measure how the 95th and 99th percentile latency and the jitter change compared with the baseline. Present the comparison in a table and a histogram.

import random
import statistics

def measure(extra_delay, seed):
    rng = random.Random(seed)
    latencies = []
    for packet_id in range(60):
        base = 8.0 + rng.uniform(-1.4, 1.4)
        queue = rng.expovariate(1 / 1.8)
        congestion = rng.uniform(0, 20.0) if extra_delay else 0.0
        latencies.append(base + queue + congestion)
    jitters = [abs(latencies[i] - latencies[i - 1]) for i in range(1, len(latencies))]
    return statistics.mean(latencies), statistics.mean(jitters), max(latencies)

baseline = measure(False, 341402)
congested = measure(True, 341403)
print("baseline:", baseline)
print("congested:", congested)
